# Submission notes

The submission uses deterministic lexical retrieval and structured reasoning, not an LLM-based RAG service. It targets Python 3.11 and needs the supplied harness and snapshots, but no third-party runtime dependency or network call. It doesnt require any API keys.

Each ingested snapshot has its own passage and typed-fact indexes. `answer(question, as_of)` selects the latest available snapshot no later than `as_of`, or the latest snapshot when no date is given, before retrieving evidence. Headings, page titles, table labels, and Markdown links improve retrieval, while answer validity is checked against source rows and qualifiers. Rates retain their measure, product, term, tier bounds, transaction, and effective-date evidence; different tiers or date generations are not silently combined. The fact resolver models snapshot, publication, effective, expiration, and reporting dates separately; missing dates do not prove overlap. The answer adapter and promotion validator only replace a lexical answer when all requested measures and applicable conditions are verified.

`conflicts()` runs the typed conflict adapter. It checks same-fact identity, row values, measure columns, source URLs, effective dates, section scope, and applicable disclosures. It groups repeated source representations while retaining distinct citations and aligned values. It reports confirmed simultaneous and verified stale-published disagreements. It excludes ordinary historical changes, unsupported auto/fee/branch comparisons, and unresolved product or transaction scope. If adapter execution or validation fails, it returns an empty list and stores an explicit diagnostic in `conflict_shadow_errors`; it never falls back to the older unverified conflict list.

Confidence depends on matching the requested qualifiers and having direct source support. The system abstains when evidence is insufficient or competing applicable claims cannot be resolved reliably. Current limits: extraction covers selected structured facts, not every fee or prose claim; a copied mortgage purchase table has a contradictory rate/term refinance disclosure and is therefore unresolved for conflict discovery. The public question set measures QA, not conflict precision or recall. A private, manually reviewed snapshot sample is used only for local evaluation and is excluded from the submission.
